This work presents a simulation-driven framework for learning and evaluating autonomous vehicle control via evolutionary neural networks within an interpretable, real-time virtual world. The methodology combines rigorous geometric modeling of drivable road networks, physically plausible vehicle dynamics, a LiDAR-like perception stack, a graph-structured neural controller, and a population-based evolutionary optimization loop. Real-time visualization of neural activations and decision boundaries supports interpretability and debugging. We also ground the environment in a real geospatial context by importing and processing OpenStreetMap (OSM) data for the Northern Helsinki area.
